# B3.3 清单校验

B3.2 记录文件当时的大小和 SHA-256；B3.3 重新读取文件，与指定的旧清单比较。
命令不写入原始资料或清单，也不会自动选取最新清单。

在项目根目录用 PowerShell 运行：

```powershell
& .\.tools\uv\bin\uv.exe run --locked --offline --cache-dir .uv-cache python -m car_knowledge_rag.verify_manifest data/manifests/zeekr/20261105T043319757600Z/manifest.json
```

默认以 `data/raw/zeekr/` 为路径基准；迁移资料后可用 `--raw-root` 指定新目录。
命令向标准输出打印 JSON，包含状态计数和问题文件相对路径。

| 状态 | 含义 |
| --- | --- |
| unchanged | 大小和 SHA-256 都与旧记录一致 |
| changed | 大小或 SHA-256 不同，包括同大小内容修改 |
| missing | 清单中已登记的文件现在找不到 |
| unreadable_or_unsafe | 无法读取或真实路径越出根目录等 |
| no_baseline | 原清单未成功登记该文件，没有可比较的指纹 |

退出码：`0` 全部一致且基准没有登记问题；`1` 有差异或基准不完整；
`2` 参数、清单格式或原始根目录不可用。无效清单不开始逐文件检查。

本地实际验证：B3.2 清单内 116 个文件全部一致。临时测试样本验证了同大小修改、
缺失、无法读取、非法路径及退出码。全套测试 61 项通过、1 项既有符号链接测试跳过，
另有 11 个子测试通过。

只检查清单已列出的文件，不扫描新增文件。校验一致不证明历史采集成功、车辆参数正确，
也无法发现原始资料与基准清单被一起篡改。使用可信清单和不会被并发修改的快照。
