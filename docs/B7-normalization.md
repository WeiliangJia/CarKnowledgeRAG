# B7：9X 配置规范化

输入是 B4 已校验解析的 9X JSON。本步不重新采集、不解析其他车型，也不做 B8 数据质量审查或 B9 人工核验。

从项目根目录运行；输出目录须尚不存在：

```powershell
& .\.tools\uv\bin\uv.exe run --locked --offline --cache-dir .uv-cache python -m car_knowledge_rag.normalize_config data/parsed/zeekr/9x-b4-verified.json data/normalized/zeekr/9x-b7-v1
```

| 文件 | 内容 |
| --- | --- |
| fields.json | 277 项行级字段定义：显示名、原标签、栏目、单位、类型与脚注引用。同名行不自动合并，字段 ID 是批次内行标识，不是跨车型通用 ID。 |
| normalized.json | 1,939 条行列记录。原文始终保留，明确的单值才填数值；可按列号回查五座、六座及版本。 |
| review.json | 124 条待核验记录：110 条含限定文字或附加值，14 条含多值或混合条件。待核验不代表原表有错。 |

三个文件均保存 B4 来源 URL、车型批次、采集时间、输入文件哈希、原始快照引用、版本列、14 条脚注和公告。记录汇总栏目、行说明及单元格的脚注引用；限定文字保留原文，不自动解释其适用逻辑。

- 明确的数值保留原表单位，不换算；乘坐人数提取数值与“人”。
- 续航分开记录 CLTC/WLTC、纯电/综合，不能只凭统一显示名比较。
- 标配、选装、不提供按原表图例标记；unknown 表示没有明确状态，不能解释成不提供。
- `55/70`、`●1082/○1050` 不填单一数值或状态；`●(两侧座椅)` 保留标配及限定文字并列入核验。

验收：全部 1,939 条原值和行列位置与 B4 一致，来源、版本及 14 条脚注均保留。Ruff 通过；76 项测试、11 个子测试通过，1 项既有符号链接测试跳过。生成结果位于 Git 忽略的 `data/normalized/`，不上传。
