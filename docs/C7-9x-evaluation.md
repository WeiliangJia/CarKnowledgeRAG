# C7 极氪 9X 评测集

2026-11-13（Australia/Sydney）。题集基于 2026-11-04 采集的极氪 9X 官网快照，覆盖配置表里的 7 个版本。以 C6 的 20 题为基础，新增 100 题，采用 96 道开发题和 24 道保留测试题。Q01–Q20 沿用 C6 的题目、上下文、预期和判定规则。

日常调试使用开发集 Q01–Q96。Q97–Q120 用于后续验收，整组保留后备厢、轮毂、连接与充电接口、拖车钩、功能开放条件五个主题。同一配置字段的题目及变体归入同一集合。两集使用相同的官网快照和版本索引，配置字段和引用的产品页正文片段没有交集。共享的版本表头、通用配置图例和用于界定资料缺失的整页查阅属于来源背景。保留集包含在仓库中，按实验记录约定仅在验收时用于评分。[实验记录模板](experiment-record-template.md)

## 文件与字段

- [开发集 JSONL](../data/evaluation/9x-dev.jsonl)
- [保留测试集 JSONL](../data/evaluation/9x-test.jsonl)

两个文件均为 UTF-8，每行一题。评测以收录的 9X 官网快照为共同背景，每题输入为 `question` 和有值时的 `context`。逐题核分使用 `expected`、`evidence` 和 `pass_rule`。

| 字段 | 内容 |
| --- | --- |
| `id` | 唯一题号 Q01–Q120 |
| `category` | 题型，对应表中的八类 |
| `group` | 配置主题，用于检查同类题的集合归属 |
| `question`、`context` | 当前问题及可选的前文或模拟摘录 |
| `expected`、`pass_rule` | 预期答案或行为及通过条件 |
| `evidence` | 结构化来源定位，可含多个来源 |
| `evidence_note` | C6 原有的文字定位及附加说明 |

`S1` 是配置表快照，`rows` 和 `columns` 分别指 B4 的行号和版本列号，均从 1 开始。可选的 `notes` 含脚注号或图例标记 `legend`。表头的版本名按列号回查。`S2` 是产品页快照，`lines` 记录正文起止行号，包含两端。`scope` 为 `snapshot` 时，表示查阅该页以判断题中所问的证据是否齐全。快照 ID、页面链接和版本索引沿用 C6。[来源与版本索引](C6-9x-evaluation.md#来源与版本索引)

判定接受语义等价和等值单位换算。事实性回答需引用对应官方来源，并满足题内全部通过条件。带「模拟输入」的冲突题将摘录作为用户给出的待核实说法。真实页面之间的表述差异按各自的版本、条件和口径判断。

验收核对了 120 个连续题号、两个集合的题数和题型、C6 原文、快照哈希及全部来源定位。两集共引用 83 个配置字段，字段和产品页正文片段均未跨集。另抽查了续航门槛、选装条件、后备厢容积与资料冲突题的预期值。题集覆盖当前 9X 快照，模型答题成绩由后续运行产生。
