# D4 极氪 9X 检索切分

D4 从 D1–D3 的固定语料包生成检索片段。先按前一步说明准备语料包，再在仓库根目录运行下列命令。[语料准备](D1-D3-9x-corpus.md)

```powershell
& .\.venv\Scripts\python.exe -m car_knowledge_rag.chunk_corpus data/corpus/9x-d1-d3.json --output data/corpus/9x-d4-chunks.json
```

命令输出 UTF-8 JSON 到新文件。语料包哈希、字符上限与片段一起保存。默认上限为 600 字符，可用 `--max-chars` 调整。完整证据超过上限时，命令会指出原文位置，便于调整上限或按来源结构细分。

| 片段类型 | 切分依据与原文定位 |
| --- | --- |
| 产品说明 | 沿用产品页正文块和章节。独立出现且紧跟上一正文块的同章节脚注合并到该块，保留精确原文行号和现有页面锚点。 |
| 配置证据 | 每个版本的每项配置各生成一条，保留车型、批次、版本、单位、原值、脚注、续航口径和核验结果。通过快照 ID、行号和列号定位配置表。 |
| 页面声明 | 产品页声明和配置页图例、公告各自可检索。 |

每条片段有稳定 UUID、`text`、`kind`、来源 URL、采集时间、来源文本哈希和定位信息。相同语料和规则生成相同结果。D5 可以按 S1 的配置表行列或 S2 的原文行号将评测证据映射到一个或多个片段。后续嵌入使用片段的 `text` 字段。

真实 9X 语料导出 1,991 个片段，包括 49 个产品说明、1,939 个配置证据和 3 个声明或图例片段。已核对全部配置行列、产品页原文行号和 C7 证据位置。重复导出内容一致，指定已有文件时命令报错并保留原文件。全量 pytest 通过 93 项和 11 个子测试，1 项既有测试跳过。Ruff 规则和格式检查通过。
