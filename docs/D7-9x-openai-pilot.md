# D7 极氪 9X 线上小样本验证

本次使用 D1–D3 固定的 9X 官网快照和 D4 规则切分。运行入口验证语料对应的快照和输入哈希，并调用 D6 已接入的两条接口。Embedding 发送 4 个公开片段和 4 个测试问题。辅助切分使用产品页的两个公开摘录，共 24 行。报告保存快照定位、模型、请求 ID、token、耗时、余弦排名和切分检查结果。[D6 调用说明](D6-openai-models.md) · [官网快照来源](C6-9x-evaluation.md#来源与版本索引)

在仓库根目录运行复现命令。每次调用生成一个新报告，使用 `.env.openai` 或同名环境变量。

```powershell
& .\.venv\Scripts\python.exe -m car_knowledge_rag.probe_9x_models --output data/corpus/9x-d7-openai-pilot-rerun.json
```
