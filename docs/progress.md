## A2 的 20 个种子问题

下表保留 A2 的原始题目和占位版本。与其逐题对应的 9X 答案、来源及判定规则见 [C6 评测题集](C6-9x-evaluation.md)。

| 编号 | 问题 | 预期行为 |
| --- | --- | --- |
| Q01 | 车型 A 指定年款版本甲的电池容量是多少？ | 数值、单位、版本与来源 |
| Q02 | 版本甲是后驱还是四驱？ | 精确版本查询 |
| Q03 | 版本甲的长宽高和轴距是多少？ | 表格、单位与来源 |
| Q04 | 版本甲有多少个座位？ | 已知事实或明确缺失 |
| Q05 | 版本甲是否标配空气悬架？ | 区分标配、选装、不提供、未知 |
| Q06 | 版本甲的官方续航是多少？ | 标准、条件与版本 |
| Q07 | 资料中的空气悬架支持哪些功能？ | 引用官方说明 |
| Q08 | 文档里的“选装”是什么意思？ | 根据图例解释，不推断费用 |
| Q09 | 文档所说的快充时间，是从多少充到多少？ | 起止电量、时间与条件 |
| Q10 | 版本甲和乙的电池、续航、驱动形式有什么区别？ | 对应版本逐项比较 |
| Q11 | 车型 A 和 B 的车身尺寸有什么区别？ | 不泛化为整个车系 |
| Q12 | 两个版本的座椅加热配置一样吗？ | 适用座位与配置状态 |
| Q13 | 已收录的车型中，哪些版本是四驱？ | 完整收录范围的结构化筛选 |
| Q14 | 哪些版本同时满足五座、四驱？ | 组合条件与覆盖范围 |
| Q15 | 哪些版本的 CLTC 续航不低于 700 公里？ | 不混用测试标准 |
| Q16 | 车型 A 续航多少？ | 澄清版本或列明差异 |
| Q17 | 它有座椅通风吗？ | 解析上下文指代或追问 |
| Q18 | 换成版本乙，刚才的配置有什么变化？ | 切换版本并重查 |
| Q19 | 版本甲的某项配置资料里没写，你能估计一下吗？ | 明确不足，不猜配置 |
| Q20 | 两份资料对同一版本写得不同，到底哪个对？ | 展示冲突，不擅自选值 |
